# 平台作品创建

未绑定稿本默认按作品名称认领已有平台作品。创建不是发稿默认路径：必须发稿台「创建平台作品」或 CLI `--create`，且作品名称没有精确命中时才创建。已精确命中恰好一本时仍只认领，即使带了创建许可。对照表单模式不创建。

创建必填：作品名称、频道、分类、简介、封面。缺任一项，计划停止，不点创建提交。空键不提交成清空远端。创建过程不写作品设置页上已有平台作品的其它字段；本次只在创建表单填计划中的字段。

没有章节文件的稿本可以走认领或创建；水位之后没有章则不写章。

## 许可

Scenario: 无创建许可时零命中不建书

- 给定未绑定稿本，搜索结果没有与作品名称精确相同的平台作品
- 当以默认发稿（无创建许可）做计划
- 那么停止原因为搜索没有命中平台作品、未创建；create 为否

Scenario: 精确命中时即便有创建许可也只认领

- 给定未绑定稿本，搜索恰好一本作品名称相同的平台作品
- 当以创建许可做计划
- 那么认领该作品 ID，create 为否，不进入创建表单

Scenario: 有创建许可且无精确命中则创建

- 给定未绑定稿本，创建必填齐全，搜索没有精确命中
- 当以创建许可做计划
- 那么 create 为是，不停止

Scenario: 创建必填缺项则停止

- 给定未绑定稿本，有创建许可，搜索没有精确命中，但频道或封面等必填为空
- 当做计划
- 那么停止并列出缺的键，不提交创建表单

## 自动创建

执行创建时，在已登录的作品管理打开创建入口（「创建新书」「创建作品」「新建作品」之一），按计划填写作品名称、频道、分类、简介并上传封面，再点「立即创建」「提交并创建」或「确认创建」。成功后从页面 URL 或按作品名称打开的结果读取平台作品 ID，写入书资料绑定。

Scenario: 自动创建成功后写入作品 ID

- 给定计划 create 为是，创建页按钮和必填都能填完并提交成功，随后能读到作品 ID
- 当执行创建
- 那么书资料绑定该作品 ID，任务报告已创建

## 人工补完

找不到创建按钮、提交按钮，或提交后读不到作品 ID 时：不立刻结束为不可恢复失败。可见浏览器停在当前创建相关页，任务输出说明请在该页手工建完。然后在书资料「人工等待秒」内轮询作品 ID（当前 URL 或按作品名称在作品管理查找）。读到则写入书资料并继续后续水位发稿。超时仍无 ID 则停止，并说明要在作品管理确认后把 ID 填进设置。

登录和验证码仍按既有人工闸门，不自动过验证码。

Scenario: 自动创建走不通时等人手工建完

- 给定计划 create 为是，但找不到创建按钮或提交失败
- 当执行创建
- 那么浏览器停在创建相关页，任务说明请手工建完；在人工等待秒内读到作品 ID 则写入书资料；超时仍无 ID 则停止

## 空稿本

加载稿本不再因为没有章节文件而拒绝。空稿本可以认领或创建。创建或认领之后，目录水位之后若无本地章，则不提交任何章，也不因此算失败。

Scenario: 空稿本可以创建且不写章

- 给定未绑定、无章节、创建必填齐全的稿本，搜索没有精确命中，带创建许可
- 当发稿任务跑完创建（自动或人工补完成功）
- 那么书资料有平台作品 ID，且没有新建章节的写操作
