# 目标

发稿台能新增本地稿本；显式创建能在番茄作家后台建成平台作品。未上架的书可以进本机列表、补齐书资料，再建成平台作品后按水位发稿。

# 范围

仅发稿：`src/publish/`、发稿台、`python -m publish`。能力分为发稿台稿本管理（列表、添加、设置里的创建必填）和平台作品创建（显式许可、自动填表、人工补完）。

已调查事实：

- 发稿台只列出 `novel/<目录>/书资料.yml` 已存在的稿本，没有添加入口。
- `load_manuscript` 在没有章节文件时抛错，空稿本今天会在发稿台标成加载失败。
- 创建平台作品必须显式许可（ADR 0010）；发稿台文案是「搜不到再创建」。
- 创建必填：作品名称、频道、分类、简介、封面。设置页目前只改绑定、可见性、发稿时刻、单次上限和等待秒，不改这些必填。
- Playwright 按固定按钮文案点创建；对不上就停止。创建成功后把平台作品 ID 写回书资料。

# 非目标

- 风向标采集、快照和看板样式。
- 改已发布章节正文。
- 走作家后台私有接口。
- 无头浏览器、自动过验证码。
- 默认发稿改成搜不到就建书。
- 改 CLI `publish init` 必须已有章节的契约。
- 发稿台从大纲灌书资料、给已有目录一键 init。
- 设置页编辑标签、子分类或其它未点名的书资料键。
- 改作品名称时重命名稿本目录。
- 拆成 Supervisor Change；本需求改同一批发稿台和 writer 文件，单个 Native change。

# 验收示例

- A1: 在发稿台提交非空作品名称后，本机出现 `novel/<作品名称>/书资料.yml`，其中作品名称已写入；响应回到 `/publish`，列表里能看见该稿本，章节数为 0 也可以。
- A2: 提交空白名称、含路径分隔符的名称、或已存在的同名目录时，不新建稿本，页面留在发稿台并显示错误，其它稿本不变。
- A3: 设置页能改作品名称、频道、分类、简介，并能上传封面；保存后这些值写入该书资料，封面文件落在该稿本目录内；改作品名称不改目录名。
- A4: 发稿台主按钮仍是「发稿」且不带创建许可；另有按钮文案为「创建平台作品」（不再出现「搜不到再创建」）；点它启动带创建许可的发稿任务。CLI `--create` 行为不变。
- A5: 未绑定、作品名称没有精确命中、创建必填齐全时，自动填表并提交成功，则书资料写入新的平台作品 ID，任务报告已创建。
- A6: 未绑定但作品名称已精确命中恰好一本时，点「创建平台作品」仍只认领该平台作品，不新建第二本。
- A7: 创建必填缺项时，不提交创建表单；任务停止并列出缺的键。
- A8: 自动创建找不到按钮或提交失败时，可见浏览器停在创建页，任务说明请手工建完；在人工等待秒内读到作品 ID 则写入书资料并继续；超时仍无 ID 则停止并说明。
- A9: 只有书资料、没有章节文件的稿本，在发稿台不是加载错误；点「发稿」或「创建平台作品」不会因「没有章节文件」在本地被拒。没有章节时不写章。
- A10: 未绑定且搜索没有精确命中时，点「发稿」（无创建许可）停止且不创建平台作品。

# 约束与不变量

- 领域词用 `src/publish/CONTEXT.md`。面向人的文字用中文。
- 稿本身份是目录；平台作品身份是作品 ID。二者不合并。
- 默认按作品名称认领；创建必须显式许可。已精确命中恰好一本时只认领。
- 空键不得提交成清空远端已有值。发稿不回写作品设置。
- 发稿台新增用作品名称当目录名；目录已存在则拒绝。
- 设置里改作品名称只写书资料，不改目录名。
- 人工创建等待复用书资料「人工等待秒」，轮询作品 ID。
- 测试离线、不开真浏览器；`writer.py` 用 FakePage。测试不读写本机 `novel/`、`outline/`、`data/*.sqlite`。

# 决策

- 工作区：独立 worktree `.worktrees/publish-add-new-book`，分支 `comet/publish-add-new-book`，目标 `main`。
- Q1：发稿台能加本地稿本，显式创建平台作品也要可用。
- Q2：发稿台只填作品名称即可建目录和书资料；没有章节也可以先出现在列表。已有章节的目录仍用 CLI `init`。
- Q3：保持 ADR 0010。默认「发稿」只认领；创建入口改为「创建平台作品」。CLI 仍用 `--create`。
- Q4：自动填表能走就走；走不通则停在可见创建页等人手工建完，再读作品 ID。
- Q5：添加表单只填名称；设置页能改作品名称、频道、分类、简介并上传封面。不加标签、子分类。
- Q6：添加成功后回到发稿台列表。
- 频道、分类、简介在设置页用文本框，不在发稿台维护番茄分类树。
- `load_manuscript` 允许 0 章；CLI `init` 仍要求已有章节。
- 单个 Native change，不拆分子任务。
