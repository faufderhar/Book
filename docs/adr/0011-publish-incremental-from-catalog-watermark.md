# 发稿按后台目录水位增量补章

原先发稿把后台整本还原成稿本加书资料（ADR 0006）。绑定把作品 ID 和章映射揉在一起，改绑困难；每次点发稿都扫整本、回写作品设置。决定：绑定只配置作品 ID，允许改绑并丢掉章缓存；每次发稿先确认目录水位，只写水位之后的章；作品设置不随发稿回写，只在显式创建时填写。

水位仍包含草稿和定时，后面的新章从最大序号之后写。例外：书资料为定时发布或立即发布时，水位之内仍为草稿的章可以改可见性，计入单次上限；已发布仍不改。
