# 番茄发稿

把本地稿本对到番茄作家后台里的平台作品：未绑定则按作品名称认领已有书，已绑定则把书资料非空项和章节终态对齐。创建不是发稿默认路径。

## Language

**稿本**:
本地一个目录里的一部小说，身份是该目录。一次发稿只对一个稿本。
_Avoid_: 作品, 书（统称）, 小说工程

**书资料**:
稿本目录内的一份权威记录，收录作家后台作品设置页上的非正文信息，以及章节可见性、连载状态。可从大纲灌默认；空着的项仍是书资料的一部分，但不表示把后台已有值清掉。绑定写在这份记录里。
_Avoid_: 元数据, 设置（统称）, 大纲

**章节**:
稿本里文件名带「第{序号}章-」的一篇。序号认文件名；标题认文内标题，没有则用文件名标题；进入后台的是去掉标题行后的纯文本。备忘和说明不是章节。
_Avoid_: 文件, 话, 节

**平台作品**:
番茄作家后台里的一部书，身份是番茄给出的作品 ID。
_Avoid_: 作品（与风向标榜单条目混淆）, 书号, 书

**绑定**:
一个稿本目录与一个平台作品 ID 的一对一关系。未写 ID 时，只按书资料里的作品名称认领；零本或多本都不写成绑定。
_Avoid_: 关联, 匹配, 对齐, 点第一本

**发稿**:
让平台作品终态与稿本加书资料一致的一次操作。尚未绑定则先认领。创建必填项只在显式创建前检查；认领已有平台作品不因封面或标签为空而停止。
_Avoid_: 上传, 同步（像双向）, 发布（单指读者可见）

**创建**:
在作家后台新建一本平台作品的显式动作。发稿默认不创建。即便带了创建许可，只要作品名称已命中恰好一本，仍只认领。
_Avoid_: 上传, 自动建书, 发稿（把创建包进去）

**认领**:
用作品名称在作品管理里找到恰好一本平台作品并写入绑定。列表行带连载或签约等后缀仍算同一本；出现两个不同作品名称才算多本。
_Avoid_: 搜索点选, 自动绑定第一本, 模糊匹配

**空键**:
书资料里已有该表单字段但值为空。发稿不把空键提交成删除远端已有值。
_Avoid_: 缺字段, 未填必填

**远端多余章**:
平台作品里有、稿本没有的章节。发稿只报告，不删、不写入绑定。
_Avoid_: 冲突章, 待删除, 同步删除

**还原**:
后台终态与本地稿本加书资料一致。不是把某次点击或请求录像再放一遍。
_Avoid_: 回放, 录制, 重放

**作家账号**:
作者本人的番茄作家登录身份，只用于自己的原创稿本。
_Avoid_: 机器人号, 多开, 工作室代发

**章节可见性**:
新章写入后台后读者能不能看见。写在书资料里，缺省为草稿。取值：草稿、立即发布、定时发布。
_Avoid_: 发布状态（与已发布章节混淆）, 上架

**草稿**:
后台已有、读者不可见的章节。
_Avoid_: 未提交, 本地缓存

**定时发布**:
新章提交审核后，到书资料里的发稿时刻才对读者可见。
_Avoid_: 本地闹钟发稿, cron

**发稿时刻**:
每天按顺序占用的钟点，例如 08:00 再 15:00。过了当天第一个点，下一章排到第二天的第一个点。
_Avoid_: 时区列表, cron 表达式

**已发布**:
读者可见的章节。发稿不改其正文，若与稿本不一致只报告。
_Avoid_: 上架, 公开, 完结

**发稿进度**:
因写操作上限或风控停下后，下一次从哪一章续。已对齐跳过、已发布不一致、远端多余章不计入上限。
_Avoid_: 断点, 游标, 任务队列

**卷**:
稿本目录里的分组，只在本地有效。v1 不写成后台分卷。
_Avoid_: 分卷, 分卷名上架

**连载状态**:
书资料里的显式字段，缺省为连载。完结必须人手写上，不根据本地章数自动切换。
_Avoid_: 完本（本地写完）, 已发布

**锁定字段**:
后台不允许再改的书资料项。发稿遇到则写入报告，不中断章节对齐。
_Avoid_: 只读, 失败

**对照表单**:
打开已认领平台作品的作品设置页，把页面标签补进书资料空键。未绑定则先认领；零本或多本则停。不打开创建页。
_Avoid_: 创建页刮字段, 探测

**写操作**:
向后台提交一章：新建草稿或更新草稿。一次发稿最多提交书资料里的单次章数上限。
_Avoid_: 处理一章, 扫描一章
